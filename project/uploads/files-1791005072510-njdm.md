# SP!CE WORKS 簡易LPリメイク｜デザイナー向けブリーフィング

Oct 2, 2026 · @p

## 1. プロジェクト概要

現行サイトを、名刺交換後に社名で調べた人が「ちゃんとした会社だ」と確認できる1ページのコーポレートサイトへ作り直します。

- **目的**：事業内容と会社の実在性（所在地・代表者・連絡先）を短時間で伝え、信頼を得る
- **位置づけ**：集客・問い合わせ獲得用のLPではなく、名刺の裏付けとなる「会社の顔」
- **成功の状態**：初めて見た人が30秒ほどで「何の会社か」「どこにある誰の会社か」「連絡手段」を把握できる
- **今回の範囲外**：実績（WORKS）セクションは掲載しない。実績が揃った段階で追加を検討
- **参考**：現行プレビュー https://preview.studio.site/live/4Ra4bve0OD

## 2. ターゲットとメッセージ

想定読者は、名刺交換などで接点を持った後に社名で検索してきた取引先・見込み客の担当者です。

- **閲覧の動機**：「どんな事業をしている会社か」「信頼して取引できるか」の確認
- **閲覧環境**：名刺を見ながらスマホで検索するケースが多い想定。スマホファーストで設計
- **伝える一言**：AIデザインに精通したメンバーを、採用せずに持てる「外付けAIクリエイティブ部門」
- **伝えたい印象**：きちんとした事業者であること。誇張した売り込みより、簡潔さと誠実さを優先

## 5. デザイントーン＆マナー

参考サイトはSUMMER SONIC公式（https://www.summersonic.com/）です。参考にするのは画面の構造と演出の考え方で、配色・ロゴ・イラストなど同サイト固有の要素は流用しません。

**参考にするポイント**

- **固定背景＋浮かぶカード**：全画面のグラデーション背景を固定し、スクロールするとコンテンツのカードだけが流れていく
- **角丸カードで情報を区切る**：白または半透明の角丸パネルに各セクションをまとめ、背景が見える余白をとる
- **鮮やかなボタン**：グラデーションの大きめのボタンで、押せる場所をはっきり示す
- **太い英字見出し**：大文字の太いサンセリフで、セクション名をリズムよく見せる
- **SPのヘッダー**：左にロゴ、右にハンバーガーメニューのシンプルな構成

**SP!CE WORKSでの適用方針**

| 項目 | 方針 |
| --- | --- |
| 全体方針 | 色数を絞り、タイポグラフィ・レイアウト・余白で見せる。装飾は最小限 |
| 印象 | ブルー一色の中に、文字組みと余白で洗練を感じさせるテック感 |
| 配色 | ブルー系のみ。濃紺〜ブルー〜シアンの階調と、白・グレーで構成 |
| 背景 | ブルー系グラデーション＋うっすらとしたノイズをコード（CSS／SVG）で表現し、全画面で固定。画像は使わない |
| カード | 白（または白90%程度の半透明）、角丸16〜24px、薄い影 |
| ボタン | ブルー系グラデーション。副ボタンは白地＋ブルー枠 |
| タイポグラフィ | 英字見出しは太い大文字のサンセリフを大きく（SPで40px前後）。和文見出し20〜24px、本文15〜16px・行間1.8〜2.0、和文の字間は少し広め（0.04〜0.08em）。番号（01／02／03）を大きく扱いリズムをつくる |
| レイアウト | SPは1カラム・左揃えを基本。英字見出し＋和文小見出しの2段構成をセクション共通の型にする |
| 余白 | 8pxを基準単位にする。セクション間はSPで80〜120pxとたっぷりとり、カード内側は24px以上 |
| ロゴ | 「SP!CE WORKS」ロゴタイプ＋S/Wシンボル。シンボルはファーストビューで使用 |
| 写真・イラスト | 人物写真は使わず、アイコンとシンボル中心 |
| 動き | 背景固定による奥行き感と、カードのフェードイン程度 |
| 可読性 | 本文は必ずカードの上に置き、背景に直接文字を載せない |

**実装メモ（Claude Code向け）**：iPhoneのSafariは背景画像の固定（background-attachment: fixed）に対応していないため、背景は画面に固定した別レイヤー（position: fixed の要素）として実装する。

## 6. 導線・検索対策

売り込みよりも「確認しやすさ」と「社名で見つかること」を優先します。

- **お問い合わせ導線**：ヘッダーの小さめのボタンと、ページ末尾のお問い合わせセクションの2か所。スマホの追従ボタンは不要
- **連絡手段**：公式LINEに加え、メールアドレス（またはフォーム）を併記。企業の担当者はLINEを使わない場合があるため
- **社名検索**：「SP!CE WORKS」「スパイスワークス」で検索した際に表示されるよう、タイトルと説明文に社名・事業内容・所在地（大阪）を含める。本番公開時は検索除外（noindex）を解除
- **名刺との連携**：名刺にサイトURLまたはQRコードを掲載すると、確認までの手間が減る
- **OGP**：URLをチャット等で共有した際に、ロゴと社名が表示される画像を設定

## 7. 制作仕様

モバイルファーストで設計し、Claude Designでワイヤーとデザインを作成、Claude Codeでコードとして仕上げます。本資料はClaude Designへの指示（プロンプト）の元原稿としても使います。

| 項目 | 仕様 |
| --- | --- |
| 設計方針 | モバイルファースト。SP 375px幅で設計を確定させてから、PC表示へ拡張 |
| ワイヤー・デザイン | Claude Design（SP版を先に作成し、PC版は確認後に展開） |
| 実装・調整 | Claude Code（HTML／CSS。デザインからの書き出しを元に余白・文字サイズ・挙動を調整） |
| ブレイクポイント | SP 〜767px／タブレット 768px〜／PC 1024px〜（目安） |
| SPの基本ルール | 本文14〜16px、タップ領域44px以上、横スクロールなし、1カラム |
| 支給素材 | なし。ロゴ・カラー・フォントは現行サイトから流用し、LINE URLとメールアドレスは当面ダミーで進める |
| SEO・OGP | タイトル、ディスクリプション、OGP画像1点、検索除外（noindex）なし |
| 公開先 | 自社で用意済みのサーバー |
